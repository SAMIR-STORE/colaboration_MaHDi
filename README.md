# متجر أزياء بالطلب عبر واتساب

مشروع صغير جاهز للتجربة في VS Code، بلا framework وبلا قاعدة بيانات. افتح `index.html` في المتصفح أو استعمل إضافة Live Server.

## فين تبدّل المعلومات؟

فتح `app.js` وعدّل:

1. `STORE_CONFIG.whatsappNumber`: رقم واتساب ديال المتجر بصيغة دولية، مثلاً `2126XXXXXXXX`، بلا `+` وبلا مسافات.
2. `PRODUCTS`: بدّل الاسم، الثمن، الألوان، المقاسات، و`image`.
3. للصور، ضع مثلاً:

```js
image: "images/ensemble-noir.jpg"
```

ثم أنشئ مجلد `images` داخل نفس المجلد وضع فيه الصور. إذا خليتي `image: ""` غادي تبان أيقونة مؤقتة.

## شنو خدام دابا؟

- سلة متعددة محفوظة في `localStorage`.
- Popup فيه الاسم، الهاتف، والمدينة.
- رسالة واتساب منظمة فيها المنتجات، SKU، اللون، المقاس، الشحن، المجموع، ورقم مرجعي فريد.
- زر شراء سريع لكل منتج.
- Outfit / Couple Builder.
- حاسبة مقاس تقريبية بالطول والوزن.
- تتبع اختياري لـ `fbq` و`gtag` إذا ضفتيهم في الصفحة.
- حفظ الطلبات محلياً، وWebhook اختياري عبر `STORE_CONFIG.webhookUrl`.

## مهم قبل الاستعمال الحقيقي

الحساب الحالي ديال المقاس تقريبي، و`localStorage` ماشي قاعدة بيانات حقيقية. للإطلاق التجاري، اربط `webhookUrl` مع n8n أو API خاص بك، وزد التحقق من الهاتف وحماية البيانات.
